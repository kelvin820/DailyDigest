# 審閱、發布與已出刊日曆

2026-11-20：日常流程已改用 `/editor` 網頁編輯室。生成在 Vercel 執行，稿件與發布存進 Supabase，網頁核准立即換刊；詳見 [WEB_EDITORIAL.md](WEB_EDITORIAL.md)。以下保留先前 Git 發刊操作作為歷史記錄。

目前採 Git 版本化發刊：刊物及檔案有雜湊、版本與發布紀錄，由 Vercel 隨 Git commit 原子部署。沒有宣稱已寫入 Supabase。網站閱讀與審查頁目前公開，DayDay 帳號仍延後；變更首頁的權限由 GitHub 保護。

## 操作流程

1. 製作：在 GitHub 的 **Generate review edition** 手動執行核對過的來源計畫。今天製作 `2026-11-19-r2` 後，經來源與分級校稿依序修訂到 `2026-11-19-r5`；歷次草稿和原始模型意見都保留。修訂沿用已核准圖片，不重複生圖。沿用已設定的 NVIDIA Secret；工作流保留原始回覆與用量。重跑會按建立時間選最新 artifact，凍結事實並重用成功步驟；未知用量或遺失圖片預留會停止，不自動重複花費。
2. 審閱：新稿成功後部署到 `/review`，首頁仍保留目前刊物。查看三版、不同程度的單字、分齡插畫、來源、模型修訂項目與六份 PDF（四格與分隔線，依內容自然分頁）。
3. 核准：審查頁的「前往核准發布」開啟 GitHub **Approve and publish edition**。點 Run workflow，填入審查頁的期刊 ID 與完整「此版編號」，勾選已審閱。GitHub 需要此 repo 的操作權限；一般訪客無法透過公開頁發布。
4. 發布：工作流重新核對同一份稿件、來源與圖片雜湊、十二份模型審稿，再生成六份正式 PDF。任一檢查失敗，首頁保持原樣。全部成功才提交發布紀錄，待 Vercel 建置成功後，訪客重新整理即看到最新已發布日期。
5. 舊刊：發布紀錄不刪除。`/issues` 的月曆和日期清單只顯示真正發布的日期。同一天多次修訂顯示最新版；未發布的試閱稿不會冒充歷史出刊。

日曆先採「月曆＋清單」：月曆方便按日選擇，清單在手機與期數少時也好找。沒有刊物的日期不提供連結，不會用假資料填滿。

## 本次試發與後續

歷史 r5 已由開發代理試發，紀錄為 `developer_test_release`，沒有逐篇人工核准紀錄；使用者之後明確要求保留這一版。新稿不沿用這個例外：程式已移除開發代理試發入口，只接受 GitHub 手動核准，記錄 `github_manual`、執行者與審閱版本。

目前沒有啟用每日排程、付費新聞 API、Google 生圖或郵件通知。來源計畫仍是實際讀取後準備的底稿，不代表自動新聞發現已驗收。未來啟用 DayDay 登入時，再以同一份不可變版本與發布檢查保護審查頁、整合站內核准，並把之後未公開的草稿切到私有儲存；目前已公開的草稿不會因為鎖頁而從 Git 歷史消失。不需要重寫刊物歷史。

正式 Supabase 路徑仍保留，服務憑證與第十五份 migration 等需求見 SETUP.md；本次網站試發不依賴這些憑證，也沒有假裝完成其資料庫驗收。

## 閱讀品質與單篇重新生成

`/review` 列出新稿比較、重新生成與歷史出刊版本。三輪原始測量在 `/review/benchmarks/2026-11-19-new-four`，每輪 12 份程度稿；保留當時硬門檻的首次通過率，再另列目前軟性長度政策的離線重檢，不增加 API 請求或回填原始成功數。

每篇顯示趣味性、資訊性、可讀性與具體模型評語。這些是模型意見，人工可另給評分與改寫方向，不等於已核准。操作「評語與單篇重新生成」：

1. 同題改寫：保留來源與事實，可選三版一起或只改目前程度。
2. 指定類別換題：政治／公民、科學、文化、遊戲、地方、自然、科技、國際、商業。必須選已讀取核對來源的候選故事，並同步三版；不拿舊圖配新事件。沒有候選來源的類別會顯示待補來源、不呼叫 API。現在政治、遊戲、地方尚無可用候選；沒有把分類選單當作自動新聞發現已完成。
3. 填方向，建立並複製 `request_json`，到 GitHub **Regenerate one story for editorial review** 點 Run workflow 貼入。用 GitHub 權限觸發，沒有在公開頁放寫入憑證，也不新增 DayDay 登入。
4. 工作流只改指定故事／程度，另外三篇與原版保留。原始回覆、時長與用量可續跑；未知用量停止。結果（含部分失敗）部署為新的待審頁，能比較原稿，不自動發布。

## 長度改為建議值

使用者已同意不再為字數或句長單獨阻擋／自動重寫。新稿以 `lengthPolicy: advisory` 明確快照；舊版無此欄位沿用舊規則，以保留不可變歷史與舊驗證結果。

| 版本 | 正文建議字數 | 建議平均句長 | 建議單句最長 |
|---|---:|---:|---:|
| 小學 A1 | 40–60 | 10 | 15 |
| 國中 A2 | 60–90 | 14 | 22 |
| 高中 B1 | 90–120 | 18 | 28 |

這些數字仍供提示與版面參考。實際難度、適齡性、必要事實、來源、正文選字、三版不重複選字與圖片／PDF 檢查仍有效。writer.v2 不為字數補空話，reviewer 也不因單純超出數字要求重寫；若語言實際不適合讀者，仍需修訂。
