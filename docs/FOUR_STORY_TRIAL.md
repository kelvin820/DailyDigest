# Four-story daily production trial

Current policy: one dated issue, four distinct events, the same events at A1/A2/B1; twelve independently written and reviewed articles, six two-page PDFs. Four-story selection covers at least three categories, with no category over two. Historical eight-story issues retain their original layout and rules.

The manual **Four Story Production Trial** workflow freezes the curated official-source plan in `config/trial-2026-11-19.json`, fetches each page and verifies exact evidence excerpts before NVIDIA requests. The official Library of Congress page can return HTTP 200 with no body on the runner. For that empty-response case only, this dated trial may use a developer-read official excerpt with capture time and integrity hash (maximum age 24 hours); the report separates live reads and reviewed snapshots. Changed nonempty pages still fail closed. It does not invent a fresh news date or pretend that this fixed trial is automatic daily source discovery. Date-only publication metadata is explicitly marked; midnight is normalization, not a known release time.

The latest completed trial artifact is resumed automatically. Source-plan context and frozen facts must match. Model changes invalidate the affected model-step hashes while preserving cumulative request/token counters. Completed requests are reused; incompatible or missing resume state fails closed. A serialized workflow and artifact reservations limit this dated trial to 70 text calls / 150,000 reserved or used text tokens and six image attempts across retries. These are request limits, not a verified dollar limit; provider prices remain unknown. Artifacts expire after seven days; expiry blocks resumption rather than silently spending again. Unknown usage requires reconciliation.

The initial Lightning 30B model repeatedly failed the elementary sentence/vocabulary gates. The current trial uses the catalog-listed `nvidia/nemotron-3-ultra-550b-a55b`; its result remains subject to the same checks. No rejected draft is marked publishable.

Vocabulary is selected for educational value and each audience in context, not from Cambridge or another purchased word list. The writer receives the easier versions' glossary terms; simple plural/case repeats are rejected. Review includes definitions, Taiwan Traditional Chinese, learning value and target difficulty. `vocabularyPolicy: tiered-v1` snapshots this rule. Historic fixture glossaries are unchanged.

Images remain photo-first. This trial uses the source's credited NIST lab photo. The telescope and reading-table concepts receive separate elementary/junior/senior prompts: bright simple shapes / approachable moderate detail / mature editorial watercolor. At most two generated concepts per edition; failed requests consume reservations and use the original category icon. All generated images are labeled conceptual, not event photos. Photos retain their documentary content. Prompt differentiation still needs visual human review; it is not proof that a generated picture is suitable.

The artifact includes actual model checkpoints, reviews, source evidence, media provenance, render verification and honest failure status. No substitute fixture body is inserted. A human copy edit may only patch an inspected real model response whose exact output hash matches `config/trial-editor-corrections.json`. Raw checkpoints stay unchanged; a separate correction record is saved, and the edited text must pass the same length, vocabulary and model-review gates. A review copy is not publication. This workflow has no cron, database write, email delivery or live publication permission.

Migration `202611190015_four_story_issues.sql` updates database staging, revisions and publication checks while preserving legacy eight-story revisions and hardened function search paths. Local database tests do not apply this migration to hosted Supabase. Hosted credentials, migration and private Storage acceptance remain separate setup items.

Minor-only model recommendations may be retained as **editorial review holds** in this manual trial when factual status, level fit and child suitability pass. Raw model recommendations stay unchanged in reviews/checkpoints; the report lists every hold. This allows a complete review packet and image/PDF testing. Production generation defaults to refusing these holds, and the publication gate still rejects `revise`; this is not approval or live publication. Critical/major issues and failed factual/level checks still stop the trial.
