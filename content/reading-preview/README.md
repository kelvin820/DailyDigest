# Bundled reading preview

The default Vercel experience is a public, read-only four-story preview. It needs
no Supabase session or model credentials. These are the actual three editions
from NVIDIA trial run 44479976061, artifact 14508046402, not fictional fixtures.
Only paths were adapted to the bundled public assets. Fonts and article content
are unchanged. The six PDFs use the cleaned reader template from commit 9639850.

The snapshot is marked reviewCopy=true, isDemo=false, publishedAt=null. It is
not a published issue, a new generation, or a database write. One minor Junior
vocabulary recommendation remains pending. Seven editorial corrections were
made by the Codex development agent; no human review completion is asserted.
Raw model replies, source evidence and editorial records remain in the private
trial artifact. The bundled files contain only the final review articles, seven
approved images with attribution, their print renditions and six review PDFs.
The rejected image is excluded. provenance.json records the source and hashes.

READING_MODE defaults to preview when unset. DEMO_MODE=true is only for legacy
fictional-fixture QA. Published member access remains available only through an
explicit READING_MODE=published setting. Preview admin routes redirect to the
reader and mutation endpoints refuse writes; /login also redirects to reading.
